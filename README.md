# Central Indiana Orthopedics — design study

A Path A pitch by [dglxss](https://dglxss.com) for the public site at [ciocenter.com](https://ciocenter.com/). This repository is not the official Central Indiana Orthopedics website and it does not book visits or take payment.

## Stack

Next.js App Router, React, Tailwind CSS. English and Brazilian Portuguese. Light and dark, saved in the browser.

## Run

```bash
npm install
npm run dev
```

Production build: `npm run build`.

The craft vote, shelf search, color pass, and tool pass are in [docs/design-meeting.md](docs/design-meeting.md).
